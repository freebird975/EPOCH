# 检索与端到端评测记录

## 全量检索基准

原工作区的主全文索引包含 64,173 篇父论文和 2,960,164 个子块。使用 Princeton NLP LitSearch 的 597 条官方英文查询与相关论文标注评估；全量语料覆盖了全部 639 个标注相关论文 ID。

已测试配置中，RRF `k=60`、每路候选数 100 的结果为：

| 指标 | 结果 |
| --- | ---: |
| Recall@5 | 0.625 |
| Recall@10 | 0.698 |
| Recall@20 | 0.752 |
| MRR@10 | 0.530 |
| nDCG@10 | 0.567 |

同一批 qrels 被用于配置选择与评估，因此这些指标不能作为独立留出集上的泛化成绩。完整 Dense 与 BM25 原始索引不包含在上传版中。

## Cross Encoder 探索

离线探索中，对 RRF 前 200 个候选重排 20 个结果后，Recall@5 从 0.625 到 0.640，Recall@10 从 0.698 到 0.701，Recall@20 保持 0.752；MRR@10 从 0.530 到 0.534，nDCG@10 从 0.567 到 0.572。差异较小，仍使用同一评测 qrels，属于探索性结果。

## 端到端评测与边界

曾用 100 篇全文试点运行 12 道问题，包括英文问题、英文题目的中文翻译和无答案挑战。中文翻译题与原英文题不独立。较新的一组在线运行因 API 额度错误而中断，不能作为完整的新旧版本对比。

需要补充的证据包括：完整的当前版本在线对比、独立留出查询、最终答案的人类事实标签，以及论文理解和相关工作生成质量的人工评审。结构化解析的 1,000 篇分支有 53,549 个子块和 BM25 索引，但其 Dense 构建未完成；这份上传版不包含该分支的文件。

上述指标来自原工作区中的历史运行记录。该 GitHub 副本不包括全量数据、索引、完整机器日志或模型缓存，不能仅凭克隆仓库复现这些结果。
